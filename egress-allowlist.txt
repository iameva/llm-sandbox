# Egress allowlist for the LLM sandbox.
#
# The proxy refuses every host that is not listed here. One hostname per
# line; text after '#' is ignored. A leading dot matches subdomains and
# the bare domain, so ".crates.io" would cover crates.io and
# index.crates.io both. Port 443 only, unless --ports says otherwise.
#
# install.sh copies this file to ~/.config/llm-sandbox/egress-allowlist.txt,
# which is where the proxy looks by default. Edit here, then reinstall.
#
# The list only takes effect in enforce mode:
#     ,egress-proxy.py --mode enforce
# In log mode the proxy allows everything and just records it, so nothing
# below is load-bearing until you enforce. Hosts and counts come from one
# log-mode run; they say what the sandbox reached, not what it needs.
